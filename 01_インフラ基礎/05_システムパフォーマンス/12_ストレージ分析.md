# ストレージの性能分析

ストレージが性能のボトルネックになると、データベースやアプリケーションの処理に待ち時間が発生します。容量だけでなく、要求の回数、転送量、応答時間を合わせて確認します。

| 指標 | 意味 |
|---|---|
| IOPS | 一秒あたりに処理した読み書き要求の数 |
| 帯域 | 一秒あたりに転送できるデータ量 |
| レイテンシ | 一回の読み書き要求にかかる時間 |
| キュー長 | 処理待ちになっているI/O要求の数 |

小さなランダムアクセスが多い処理はIOPSや応答時間、大きな連続読み書きは帯域が制約になる場合があります。読み書きの割合やI/Oサイズも性能に影響します。

ディスクやストレージを追加しても、構成や製品の上限によっては性能が上がらないことがあります。実際の負荷、遅延、待ち行列を測定し、ストレージ層の制約か確認します。

たとえば、データベースが小さなランダム読み込みを大量に行う場合は、転送量が小さくてもIOPSや一回ごとのレイテンシが問題になります。大きなバックアップファイルを連続して読み書きする場合は、IOPSより帯域が制約になりやすくなります。用途に合った指標を選びます。
