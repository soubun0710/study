# レイヤー5～7

OSI参照モデルのレイヤー5から7は、アプリケーション間の会話、データの表現、サービスの利用方法を整理するための層です。現代のTCP/IP通信では、これらの機能が一つのプロトコルやアプリケーションへまとめて実装されることもあります。

- **レイヤー5：セッション層**：通信相手との会話や、その開始、維持、終了を扱う考え方
- **レイヤー6：プレゼンテーション層**：文字コード、データ形式、圧縮、暗号化などの表現を扱う考え方
- **レイヤー7：アプリケーション層**：HTTP、DNS、SMTPなど、アプリケーションが利用する通信プロトコルを扱う

たとえばWebブラウザーがHTTPSでページを取得するとき、アプリケーションの要求が通信プロトコルを通じて送られます。TLSによる暗号化などの機能はOSIの一つの層だけに単純対応するものではありません。

## プレゼンテーション層とアプリケーション層のたとえ

- **プレゼンテーション層**：資料を日本語から英語へ翻訳したり、PDF形式に整えたりするように、相手が扱えるデータの表現や形式を整えるイメージです。
- **アプリケーション層**：顧客が相談や手続きをする窓口・営業のように、利用者の要求を受け付け、Webやメールなどのサービスへつなぎます。

この分類は通信の仕組みを考えるためのモデルです。障害調査では層の名称を手掛かりにしつつ、実際のログや通信の状態を確認します。

## 参考資料

- ITU-T, Recommendation X.200, *Information technology — Open Systems Interconnection — Basic Reference Model: The basic model*（1994年、国際勧告）。セッション層からアプリケーション層までを含むOSI参照モデルを定めています。[ITU-T公式資料](https://www.itu.int/rec/T-REC-X.200/en)
- IETF, RFC 8446, *The Transport Layer Security (TLS) Protocol Version 1.3*（2018年、TLS仕様）。TLSのプロトコル動作を確認する資料です。[RFC Editor](https://www.rfc-editor.org/rfc/rfc8446)
- IETF, RFC 9110, *HTTP Semantics*（2022年、HTTP仕様）。HTTPの意味論を定めています。[RFC Editor](https://www.rfc-editor.org/rfc/rfc9110)
