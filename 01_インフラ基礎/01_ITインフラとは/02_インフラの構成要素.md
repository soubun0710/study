# ITインフラの構成要素

ITインフラは、アプリケーションを実行し、データを保存し、利用者や他のシステムと通信するための基盤です。どの要素が必要かはシステムによって異なりますが、主に次の要素で構成されます。

| 要素 | 主な役割 |
|---|---|
| サーバー | アプリケーションなどの処理を実行する |
| OS | CPUやメモリ、ファイルなどを管理し、ソフトウェアの実行を支える |
| ネットワーク | 利用者やサーバー同士の通信を中継する |
| ストレージ | OS、アプリケーション、業務データを保存する |
| ミドルウェア | データベースやWebサーバーなど、アプリケーションが使う共通機能を提供する |
| アプリケーション | 利用者や業務が必要とする機能を提供する |

たとえば、利用者がWeb画面から注文すると、ネットワークを通じてサーバー上のアプリケーションへ要求が届き、必要なデータをストレージやデータベースから読み書きします。

アプリケーションは一般にインフラの上で動くものですが、システム全体を理解するため、インフラと合わせて構成図に表すことがあります。構成要素の分け方や責任範囲は、組織やサービスによって異なります。
