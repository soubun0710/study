# 情報セキュリティリスクの評価と対応

組織は、情報資産にどのような損失が起こり得るかを評価し、対応するリスクと受け入れる残余リスクを決めます。評価方法や判断基準は組織ごとに定めます。

## リスクへの対応

- **回避**：リスクを生む業務や仕組みをやめる
- **低減**：対策を実施して発生可能性や影響を下げる
- **受容**：組織の基準と権限に基づいて残るリスクを受け入れる
- **共有・移転**：保険や契約などで影響の一部を他者と分担する。委託しても、委託元の責任や残余リスクがなくなるわけではない

## リスク評価の例

| 項目 | 内容 |
|------|------|
| 情報資産 | 顧客データベース |
| 想定シナリオ | 未修正の脆弱性を悪用した不正アクセス |
| 発生可能性、影響 | 組織で定めた基準に沿って評価 |
| 対応例 | 脆弱性の修正、アクセス制御、監視 |
| 判断 | 対応後の残余リスクを確認し、権限者が判断 |

情報の分類では、閲覧できる人、保存場所、共有方法、保存期間、廃棄方法などを組織の基準に沿って定めます。分類名や評価尺度に唯一の共通形式があるわけではありません。
